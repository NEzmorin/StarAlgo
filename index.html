!Как загружать файлы и картинки!

Чтобы экономить место и ускорять StarAlgo, не загружайте большие файлы напрямую на сайт. Сначала разместите файл на одном из разрешённых внешних сервисов, затем вставьте прямую HTTPS-ссылку в проект.

Сервисы и для чего они подходят: image2url.com — изображения; catbox.moe — файлы, в том числе .sb3; imgbb.com / ibb.co — изображения и GIF; posty5.com — одна HTML-страница (не ZIP/многофайловый сайт); GitHub Pages — сайты, HTML и статические файлы, в том числе .sb3; Vercel — сайты и веб-приложения; Google Drive — видео и документы: включи «Доступен всем, у кого есть ссылка», для видео StarAlgo откроет предпросмотр; Google Docs — разговорники и документы; pagedrop.io — файлы/страницы; перед загрузкой проверь ограничения и тип прямой ссылки; boomurl.com — статические сайты и HTML/CSS/JS, не хранилище видео или файлов; iimg.live — изображения, GIF и видео MP4/WebM/MOV; x02.me — изображения, видео MP4/WebM/MOV и другие файлы.

Встроенные файлы: можно ссылаться на cover.png и emptyprofile.png. Ссылки должны быть HTTPS и вести непосредственно к файлу или опубликованному проекту. Для Scratch можно вставить ссылку на опубликованный проект Scratch (откройте свой проект и нажмите «Поделиться») — он откроется во встроенном Scratch-плеере. Либо скачайте .sb3 из Scratch и разместите файл на GitHub Pages или другом хостинге с прямой ссылкой. Для опубликованных проектов Scratch используется официальный плеер. Для внешнего .sb3 в TurboWarp нужна прямая ссылка на файл и поддержка CORS.

Сайт принимает новые внешние ссылки только с перечисленных доменов. Не вставляйте пароли, приватные документы или ссылки с ограниченным доступом.
